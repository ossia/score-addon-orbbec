# Azure Kinect backend

`k4a/k4a.h` and `k4a/k4atypes.h` are vendored verbatim from the
[Azure Kinect Sensor SDK](https://github.com/microsoft/Azure-Kinect-Sensor-SDK)
(MIT). `k4a_export.h` and `k4aversion.h` are normally generated by that project's
CMake; the copies here are stand-ins.

The headers are used only for types and signatures: the backend resolves libk4a
with `dlopen` at runtime rather than linking it. That keeps this target buildable
on any machine — CI included — without the SDK present, lets a user install the
SDK through their own package manager, and sidesteps redistributing
`libdepthengine`, which is a closed Microsoft binary the SDK requires for any
depth output and which we have no licence to ship.
